Your Upcoming Coding & Design Exercise: What to Expect
We are looking forward to our upcoming technical session with you! To help you prepare, here are the core details of the 3-hour exercise:
🛠️ Technical Details & Environment
The Challenge: You will build and deploy a functional REST API service that handles data ingestion and processing based on requirements we provide.
Languages: We prefer Go or Python, but you are welcome to use any language you are most comfortable with.
Hardware & AI (Updated): We will provide a laptop for the session equipped with Cursor Enterprise.
Note on AI: Cursor is an AI-first IDE (built on VS Code) that includes native, unrestricted access to frontier models like Claude 3.7 Sonnet and GPT-4o, completely replacing the need for separate GitHub Copilot or Anthropic licenses. You are welcome to use these built-in AI tools to work efficiently. Strict data privacy modes are enabled.
Deployment: This is a full-cycle exercise. You will be provided with DigitalOcean cloud credits and will be expected to deploy your service to the platform during the session.
Tips for Using Cursor During the Exercise
If you haven't used Cursor before, we highly encourage you to leverage its AI features during the exercise. It is designed to act as your pair programmer. Here are the three primary shortcuts to keep in mind:
Cmd + L (or Ctrl + L) — AI Chat: Opens a sidebar where you can ask high-level architectural questions, bounce design ideas around, or ask about the repository. (Tip: Use @codebase to ask questions about the entire project).
Cmd + K (or Ctrl + K) — Inline Edit: Highlight a block of code and type instructions in plain English to refactor, fix bugs, or write tests right on the page.
Cmd + I (or Ctrl + I) — Composer / Agent Mode: If you want the AI to help you build out a feature across multiple files or run terminal commands to test your code, this is the tool to use.

Testing: Evidence of a structured approach to verifying code through automated testing.

Operational Excellence: Consideration for live environments, including observability, configurability, and scalability.
