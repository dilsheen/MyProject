Event

  "occurredAt": "2026-10-21T11:00:00Z",
  "value": 1.5

eventId: required, client-supplied unique id
type: required, non-blank

Endpoints

GET /health → 200 {"status":"up"} (no DB)
GET /ready → 200 if Postgres is up, else 503
POST /v1/events → create or return existing
POST /v1/events:batch → { "events": [ ... ] }, max 100

Status codes

200 duplicate (idempotent replay)
201 new event
200 batch: { "accepted": [...], "rejected": [{ "eventId", "reason" }] }
400 invalid JSON / validation
404 unknown event
500 unexpected; JSON error, no stack trace in the body
Error shape


{
  "error": "validation_failed",
  "message": "occurredAt must be ISO-8601",
  "details": [{ "field": "occurredAt", "issue": "invalid_format" }]
}
Batch rules

Invalid rows go in rejected; valid rows are stored
Duplicate eventId in the batch (or already stored) counts as accepted (idempotent), not rejected
Empty events array → 400
